# Repository boundary

ForgeMCP is the generic assembly project.

## In scope

- goal / requirement decomposition
- atomic Capability modeling
- prior-art and implementation discovery
- Contract inspection
- implementation selection
- dynamic composition
- adapters and glue governance
- assembly/build execution patterns
- verification and regression patterns
- provenance, evidence, replaceability and feedback loops

## Out of scope

Domain product logic is not stored here merely because ForgeMCP helped assemble it.

For the current image project, the following belong in `pic-mcp`, not ForgeMCP:

- Booru / Pixiv source integrations
- image recommendation ranking
- related-tag product logic
- pHash / image duplicate product integration
- visual embedding and image-to-image retrieval
- image session preference and feedback state
- image-specific MCP tools and rendering

Repository: https://github.com/fengyuany857-beep/pic-mcp

## Canonical boundary

The formal Universal Project Organ documents in Google Drive remain authoritative for the current architecture/specification state. Repository files are implementation assets and pointers unless a future formal governance change explicitly promotes them.
